# Requesting an account

## Before requesting an account

GENis uses a **two-factor authentication system (2FA)** to strengthen the security of user access.

This system is based on the use of authentication apps installed on the user's mobile phone, such as Google Authenticator or other compatible apps.

These apps generate one-time passwords (OTP: One-Time Password), which change automatically every few seconds.

Unlike traditional (static) passwords, the dynamic passwords generated by this system cannot be reused, which significantly reduces the risk of unauthorized access even if the user's password has been compromised.

The password consists of 6 digits and regenerates every 30 seconds. To start using it, the app must first be downloaded to the user's own mobile phone (depending on the case, this may be from Google Play Store, the App Store, or others). Keep in mind that in order to take advantage of this feature, the phone's clock must be synchronized with the GENis system server's clock; otherwise the code will be rejected. To this end, the phone will be configured so that synchronization is automatic or, if manual synchronization is preferred, it will be verified that the phone shows the time displayed on the following page:

**_https://24timezones.com_**

## Requesting an account

Before accessing GENis, the user must request the administrator or installation staff to create an account with certain roles defined by an administrator.

As mentioned, GENis provides a two-factor authentication mechanism, so to log in, in addition to the username and password, the token code provided by the Google Authenticator app (described in [Before requesting an account](#before-requesting-an-account)) must also be entered.

![](images/sec02/p018_f01.png)

Click Request an account and enter the details to generate the registration request.

![](images/sec02/p019_f01.png)

*Fields marked in red with * (asterisk) are mandatory. The Request registration button will not be enabled until all mandatory fields are completed.*

Keep the following considerations in mind:

- The **GeneMapper** User field must match the person responsible for loading the profile.

- The predefined **Superuser** role must be assigned to users who have permission to work on all genetic profiles in the GENis instance, regardless of which user added them to the system.

- Note that the only role that comes by default in the tool is the administrator role. Additional roles may be created and configured as needed, for example: Auditor, Technician, Administrative, etc.

Once all the details have been completed, click **Request registration**.

![](images/sec02/p020_f01.png)

GENis will offer alternative usernames based on the first and last name entered. Select the one you prefer and then, using Google Authenticator, scan the code or enter the provided key. This will generate a 6-digit code that must be entered in the "OTP Code" field to confirm the user registration request.

![](images/sec02/p021_f01.png)

## Activating a user account

The administrator user, or whoever has sufficient permissions to approve access for new users, will receive a new notification in their notification inbox indicating that there is a pending user request awaiting approval.

![](images/sec02/p021_f02.png)

Click on the notification or go to the **Settings/Security/Users** menu to access the user pending activation:

![](images/sec02/p021_f03.png)

The administrator user must verify that the requesting user is indeed the one making the request and that the requested permissions are correct.

Prior to approval, the administrator can check and modify the requested roles, if necessary, by clicking the edit icon

![](images/sec02/p022_f01.png)

The administrator can modify the data and/or roles assigned to the user and save the changes.

To effectively register the user in GENis, change the user's status to **Active**.

![](images/sec02/p022_f02.png)

## Password reset

For a user to be able to reset their password, the administrator user must change the requesting user's Status to **Pending reset**. If the user is not in this status, they will not be able to reset their password:

![](images/sec02/p022_f03.png)

Once the user is in **Pending reset** status, go to the **Forgot my password/TOTP** option and the reset can be performed:

![](images/sec02/p023_f01.png)

A new provided key is generated:

![](images/sec02/p023_f02.png)

Once the new TOTP code has been entered, a password reset confirmation message appears:

![](images/sec02/p023_f03.png)

To complete the password reset, the administrator user receives a notification that there is a user pending approval. The administrator user must change the user's status from **Pending approval** to **Active**.

If this status change is not made, the requesting user will not be able to access GENis.

Whenever a password reset is performed, the system assigns a new QR code for generating the TOTP.

## Blocking access to a user account

A user with administrator permissions can block a user's access by going to the **Settings/Users** menu and selecting the **Blocked** status:

![](images/sec02/p024_f01.png)

A user is blocked when misuse of the application is detected, for example, when several failed system access attempts are detected within less than five minutes.

## Deactivating a user account

To deactivate a user account, go to the **Settings/Security/Users** menu and select the **Inactive** status:

![](images/sec02/p025_f01.png)

Deactivating a user is a planned action carried out for a specific period, for example, when a user goes on vacation; the account is deactivated so that access to the system remains disabled during that period.
