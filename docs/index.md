# Documentación GENis

Bienvenido a la documentación funcional del sistema **GENis**, la plataforma de gestión de perfiles genéticos y bases de datos forenses de ADN desarrollada como bien público digital.

Usá el menú de navegación para recorrer las distintas secciones, desde la declaración de principios y la introducción al sistema, hasta los anexos técnicos sobre algoritmos de coincidencia, estadística forense y protección de datos personales.

**Repositorio:** *https://github.com/fundacion-sadosky/genis*
