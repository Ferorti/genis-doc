# 3. Roles

![](images/sec03/p028_f01.png)

## Roles

GENis provides the ability to create roles that are then assigned to users and define the operations they can perform in the system.

To access the role configuration, select **Configuration/Security/Roles** from the menu

![](images/sec03/p029_f01.png)

On the left are the roles configured in GENis, and on the right are the permissions that can be granted to the role:

![](images/sec03/p029_f02.png)

![](images/sec03/p029_f03.png)

By checking the permission's checkbox, it becomes active for that role. The icon shows a brief description of the permission.

## Adding a role

To add a new role, click the **Add role** button on the left-hand side and assign it an ID and a name.

The ID must contain at least 4 characters and must not contain spaces or accented characters:

![](images/sec03/p030_f01.png)

Each role is assigned a series of permissions, which in turn group a set of operations that will be enabled for the user or users assigned that role (see next section: Role configuration).

## Role configuration

In the menu on the right are the names of the permissions that can be assigned to the role, a brief description of them, and by clicking the information button you can access the detail of the operations that can be performed when that permission is assigned to the role:

![](images/sec03/p031_f01.png)
