# GENis Documentation

Welcome to the functional documentation of the **GENis** system, the genetic profile management platform and forensic DNA database developed as a digital public good.

Use the navigation menu to browse the different sections, from the declaration of principles and the introduction to the system, to the technical annexes on matching algorithms, forensic statistics, and personal data protection.
